
## Project Summary

This project is a full-stack Task Manager application built to practice modern web development concepts using Next.js and Express.js.

### Features

- Display all tasks in a clean, responsive interface.
- Navigate between tasks using **Previous Task** and **Next Task** buttons.
- Add new tasks through a dedicated form.
- Edit existing tasks with pre-filled form data.
- Delete tasks from the application.
- Inline form validation for required fields and invalid input.
- Loading and error state handling while fetching data.
- Responsive user interface built with Tailwind CSS.
- Component-based architecture using reusable React components.
- Backend stores tasks in an in-memory data source during runtime.
- Frontend and backend communicate using HTTP requests.
- Built with TypeScript for improved type safety and maintainability.

### Technologies Used

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Node.js
- Express.js

## Overview

This project is a full-stack Task Manager application developed using Next.js, React, TypeScript, Express.js, and Tailwind CSS. It allows users to view, add, edit, delete, and navigate through tasks using a clean and responsive interface. The project demonstrates frontend and backend integration, state management, form handling with validation, reusable React components, and server-side data handling using an in-memory data source.
